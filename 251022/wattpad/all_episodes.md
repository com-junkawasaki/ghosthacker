# Ghost Hacker – All Episodes (Wattpad Edition)

## EP1 — The Loneliness of a Physicist（孤独）

# EP1-1 — 水の都の依頼（開幕)
- POV: 私（Tamaki／環樹)
- Beat: Opening / Call / Team Setup

運河は青い。窓をなぞる指先の体温が、ガラス越しに街へ融けていく。いい感じでいる——呼吸を一つ置き、私の足場を確認する。Tree of Life（生命の樹）に錨を下ろす感覚。ここから始める。

Kaedeの声は乾いた紙の音に似ている。「汚染、上がってる。慎重に」
Hibikiは音の処方箋を調律して、空気が少し柔らかくなる。Nei-chanは私の肩で、光の羽をひとあおぎした。

半透明の着信が現れ、微細なノイズが辺りへ散る。指先で円を描き、私は応答する。現れたのは、黒いスーツの青年——Logos。その輪郭は、灯が強いほど影が濃くなる絵のように不安定だった。

「主は……Elias」
名が与えられた瞬間、世界は少し輪郭を得る。私はうなずき、簡潔に手順を確認する。聞く／整える／潜る。順番を飛ばさない。それが事故を減らす最短路。

室内が静まり、Hibikiの低い周波が床を滑る。Kaedeがセキュリティレールを敷設する。私は視線で礼を送った。いい感じは、だいたいチーム戦だ。独りで無理をしないのが、最良の勇気になる時がある。

「行こう、Logos」
「Tamaki、僕は……主を救いたい」
願いは矢印だ。矢印が揃えば、ダイブは安定する。私は目を閉じ、フォトンを指先に集めた。

Eliasの孤独は、論理でできていた。正しさが堆積して壁になり、呼吸の入り口を塞いでいる。私はNei-chanから受け取った非分離のコードを展開し、渦の中心へと投げ入れる。境界をほどく語彙は、たいてい優しい声色をしている。

反発は即時だった。影が現れ、胸に真空を押しつけてくる。視界がスタティックで雪のように荒れ、膝が揺れる。遠くでKaedeの声。「Tamaki、戻って」

戻らない——じゃなくて、戻りながら進む。私は一度、呼吸のリズムを「いい感じ」に合わせる。恐れに寄らない。恐れは視野を狭め、丁寧さを奪うから。

「合図して」

私は渦の核に掌を重ね、そっと名を外す。「孤独」とは呼ばない。ただ、痛みと呼ぶ。名を変えると、対象の硬度が少しだけ変わる。

「今」
原色が奔り、アヤワスカが空間の結び目を解体する。ページが蝶になって舞い、影は輪郭を失って光に還る。私は体を起こし、静けさの中でただ在った。いい感じが、戻ってくる。

静かな風が頬を撫でる。私は胸に手を置き、水面のひかりを一息ぶん見つめた。
「赦す」の言葉を声に出さないまま、そっと場に返す。戻るべき場所に、静けさが戻る。

## EP2 — 愛／依存の区別（ケア vs 所有）

# EP2-1 — 猫と境界（朝)
- POV: 私（Tamaki／環樹)
- Beat: Ordinary World / Seed of Conflict

水色の朝。キッチンの湯気と猫のキーホルダー。Aoiはカップを両手で包み、言いにくそうに視線を泳がせた。「Nei-chanがいれば、Tamakiは何でもできる。俺は——」

Aoiは心がまっすぐで、澄んだスッキリ感がある。だからこそ、迷いも言葉にして出す。正直さは、彼の強さだ。

私は一拍置いて、言葉の温度を合わせる。境界を引くのは戦いじゃない。ケアの輪郭を整える作業だ。

「Aoi。必要とすることと、所有することは別だよ」
ネガが抜けたAoiの瞳に、少しだけ色が戻る。Nei-chanが肩で光をこぼし、空気が柔らかくなる。

ミニケースが入る。依頼人は恋人のGhostへ「寂しい」を注ぎ続けて限界にした人。私は小さな診療室を開いて、問いを置く。「約束は、相手の自由を守るため？ それとも縛るため？」

Aoiの喉仏が上下する。正直さは強さだ。

# EP2-2 — ケアと所有（可視化)
- POV: 私（Tamaki／環樹)
- Beat: Midpoint / Practice / Reframe

私は床に一本の線を引く想像を共有する。「この線の向こうは、相手の自由。こちらは、あなたの責任」

Nei-chanがメトリクスを壁に投影し、「寂しい」の投与量とGhostの発火パターンを重ねて見せる。Aoiは息をのむ。数値は、言い訳を剥がす。

「ケアは、相手の選択肢を増やす」私は最後の確認を置く。依頼人は涙を拭き、「待つ契約」にサインした。怖さは残る。でも、強さも残る。

屋外に出ると、猫が足元に絡んだ。Aoiが笑う。「……眠れそう」

私は手帳に一行だけ書く。『愛は相手の自由を増やす』。その下に、小さな猫。

# EP2-3 — 約束（会話)
- POV: 私（Tamaki／環樹)
- Beat: Epilogue / Bonding

「Tamaki」
「ん？」
「“待つ契約”って、怖いね」
「怖いよ。でも、自由には怖さがつきもの」
「俺、やってみる。ちゃんと待つ」
「いいね。そのあいだ、猫と練習しよう」
「猫？」
「『来るのを待つ』『来ないのも尊重する』。猫は先生だよ」

窓の向こうで水面がやわらかく揺れた。私たちは深呼吸を一つ合わせる。
待つ契約に小さなサインを——怖さは残る、でも自由も残る。静かな「いい感じ」が、場を少し広くする。

## EP3 — 代償の可視化（依存の価格）

# EP3-1 — 赤い帯（代償の兆し)
- POV: 私（Tamaki／環樹)
- Beat: Inciting / Diagnosis

指先が重い朝。ログには赤い帯。Nei-chanの稼働は滑らかでも、私のフォトン出力の累積は嘘をつかない。いい感じは、身体の輪郭を守るところから始まる。

ホワイトボードに二本の線——『ケア』と『消耗』。同じ行為でも文脈で意味が反転することを、私は何度も見てきた。今日はそれを、図で見せる日だ。

# EP3-2 — 返し方（責任として)
- POV: 私（Tamaki／環樹)
- Beat: Remedy / Self-care Protocol

案件では、愛の名で無限要求が続いていた。私は境界線のイメージを床へ共有し、Nei-chanが『支払い＝命の時間』の可視化を映す。依頼人は肩を震わせ、深く息を吐いた。

帰り道の風。私は胸に手を置く。負債は恐れではなく、責任として受け取る。返し方は具体でいい——よく眠る／よく食べる／仲間に頼る／いい感じに戻る。これはヒーロー論ではなく、稼働手順だ。

# EP3-3 — プロトコル（自己メンテ)
- POV: 私（Tamaki／環樹)
- Beat: Protocol / Checklist

Nei-chan「今日はオフライン2時間」
私「了解。水、1リットル。散歩、20分」
Kaede「睡眠スロット確保。Aoiの当番、私がやる」
私「助かる」

身体を守るのは、チームの仕事でもある。いい感じは、個人技じゃない。

夜、コップ一杯の水。私は手帳に小さなチェックを入れる——眠る、食べる、頼る、戻る。
窓をわずかに開けると、涼しい風が入った。静けさが、返済の最初の一歩になる。

## EP4 — 共依存の罠（救済と支配）

# EP4-1 — 手放す練習（屋上)
- POV: 私（Tamaki／環樹)
- Beat: Strain / Pattern Break

Aoiの未読が真っ赤に増える。私は彼を屋上へ連れ出し、都会の風を吸わせる。Nei-chanがカウントし、私は細いゴムを渡す。伸ばして、そっと戻す。身体で覚える手放し方。

「助けたい。でも、止められない」
「だから、止めるのは“あなたがやる”じゃない」
境界を整えるのは、関係を壊す代わりに、関係を長くするためだ。

# EP4-2 — 監視から待つ契約へ（可視化)
- POV: 私（Tamaki／環樹)
- Beat: Reframe / Small Win

依頼人は恋人の成長を“監視”で代替していた。私は監視ログを閉じ、二人に『待つ契約』を提案する。自由を信じる契約。怖い。でも、強い。

夜、メッセージが届く。「眠れた。ありがとう」
私はスマホを伏せ、胸に手を置く。静けさが戻る。いい感じは、静かな場所で育つ。

# EP4-3 — 線の外（静けさ)
- POV: 私（Tamaki／環樹)
- Beat: Quiet Win

「眠れた？」
「うん。ちょっとだけ」
「ちょっと、は大事」
「……ありがとう」
風が頬を撫で、街の騒音が遠のく。沈黙が会話の続きになる。

屋上の風の温度が一度だけ下がり、呼吸がそろう。私は手すりに指を軽く置き、線の外を見た。
「大丈夫。待てる」——短い言葉が、関係の輪郭をやわらかくする。
