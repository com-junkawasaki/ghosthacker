# EP8-2 — I AM THAT I AM（収束）
- POV: 私（Tamaki／環樹）
- Beat: Release / Return

恐れは輪郭を得て、小さくなる。私は彼に道を示す。「還ろう」

Nero Opsが最後の抵抗をする。『還る場所はない。システムの外は、カオスだ。非効率な感情は、排除されるのが合理的帰結だ』

私は首を振る。「還る場所は、関係の中にある」

Kaedeの声が通信に入る。彼女の声は、迅速で、確実だ。

Kaede「Neroの通信経路、遮断する！」

彼女の動きは、救急医のそれ——迅速で、正確。

Hibikiの周波数が空間を満たす。彼の声は、力強い。

Hibiki「Ogreの周波数、中和するよ！」

彼の音が、敵対的な周波数を包み込む。

原色の川が流れ、Tree of Lifeが静かに受け止める。胸の奥で、はっきりと在る。「I AM」。

運河に朝の風。いい感じは、いつも静かで、強い。私は仲間たちと視線を交わし、次の依頼に備える。
私は最後にもう一度、偽神の跡地を振り返る。恐れが抜けた空白は、静けさで満たされる。Renが手を挙げ、小さく笑った。「還ったね」
