# EP12-1 — Together（いっしょに）
- POV: 私（Tamaki／環樹）
- Beat: Collective Release / Quiet Union

最後の合図は、静かに。私は神楽を踏み、Hibikiが呼吸を整える。Kaedeが結界を見守る。Nei-chanの光が広がり、街の輪郭が少し柔らかくなる。

「わたしは在る」
その言葉は誰かの所有物ではない。恐れが手を離し、関係が立ち上がる。Neroは去っていく。勝利じゃない。還るだけだ。

朝の運河。私は手帳に一行を書く。「We can't put it toghether. it is toghether.」
そして、ページの端に小さな“木”を描いた。

私はみんなを見る。Kaede、Hibiki、Nei-chan——視線が重なり、自然にほどける。
「いっしょに」その一言で、場が明るくなる。水音が遠くで応える。
