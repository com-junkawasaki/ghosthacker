# Spirit in Physics — Style Guide

## Format
- **形式**: Graphic Novel（左綴じ、左→右読み）
- **判型**: B5 (182×257mm)
- **カラー**: フルカラー水彩風
- **言語**: 日本語 / 英語 並行版

---

## 1. カラーパレット

### 基調: 透明水彩タッチ
紙のテクスチャが透ける淡い階調。水の都・東京2065年の湿度と光を水彩の滲みで表現する。

### 巻別テーマカラー

| 巻 | テーマ | 主調色 | 副調色 | 精神世界アクセント |
|----|--------|--------|--------|-------------------|
| Vol.1 孤独と輪廻 | 分断と接続 | 群青 (Ultramarine) | 灰白 (Ash White) | 琥珀の光 (Amber) |
| Vol.2 依存と共依存 | 代償と負債 | 深緑 (Viridian) | 錆色 (Rust) | 淡紫 (Lavender) |
| Vol.3 正義とシステム | 制度と公正 | 鉛色 (Gunmetal) | 朱 (Vermilion) | 白金 (Platinum) |
| Vol.4 神学とI AM | 名と非二元 | 紺 (Navy) | 金 (Gold) | 純白 (Pure White) |
| Vol.5 彼岸 | 統合と主体化 | 全色の融合 | — | 虹色のにじみ |

### 使い分けルール
- **現実世界**: テーマカラーの淡いウォッシュ、白地多め
- **精神世界（ダイブ中）**: テーマカラーが濃く広がり、アクセント色が発光
- **回想・フラッシュバック**: セピア + テーマカラーの一色のみ
- **クライマックス**: 紙の白が消え、全面が色で覆われる

## 2. 画風リファレンス

### 主要参照
- **天野こずえ** (ARIA, あまんちゅ!)
  - 水・空・光の透明感
  - 沈黙と余白で語る間の演出
  - 日常の中に宿る聖性の描写
  - 建築と水面の反射表現

- **田村由美** (7SEEDS, BASARA, ミステリと言う勿れ)
  - 精密でダイナミックな線描
  - 内面の感情が身体の重心・手のしぐさ・視線に現れる
  - 強い意志を持つ女性キャラクターの立ち方
  - 文明と自然の対比

### 統合方針
天野の「空気感・水・光」と田村の「線の知性・感情の身体表現」を融合する。
天野の柔らかさが世界を包み、田村の精密さがキャラクターを刻む。

---

## 3. 線画

### キャラクター
- 繊細で精密な線。ペン入れではなく、鉛筆の息遣いが残るタッチ
- 身体の重心、手のしぐさ、視線の向きで内面を語る
- 衣服は機能と文脈に基づく。過剰な装飾はない
- キャラクターは背景と同調し、空間に「居る」こと自体が表現

### 背景
- 有機的で微細なプロセスによって生成された未来世界
- 建築・構造体・地形・空気・光・情報ネットワークが生きている
- 自然と機械、生物とコードが区別されず融合
- 線は知性と感情を同時に伝え、空間は記憶と時間を孕む

### 精神世界
- 現実世界の線のルールが崩れていく
- 輪郭線が滲む、溶ける、増殖する
- 抽象と具象の境界が曖昧になる
- ゴーストは「線の不在」で表現（周囲だけが描かれ、本体は白抜き）

---

## 4. コマ割り・レイアウト

### 基本方針
Graphic Novel の自由レイアウト。テンプレート的コマ割りは使わない。

### パターン

| シーン | レイアウト |
|--------|-----------|
| 日常・導入 | 4-6コマ / ページ、規則的グリッド |
| 対話・内省 | 2-3コマ / ページ、余白多め |
| 精神世界ダイブ | 見開き、境界線なし、全面絵画 |
| クライマックス | 見開き or 1コマ1ページ |
| 静寂・余韻 | テキストなし、1-2コマ、大きな余白 |
| 回想 | 角丸コマ、セピアトーン |

### 余白の哲学
- 余白は「空（くう）」であり、「無」ではない
- 沈黙のコマ（セリフなし、表情と空間だけ）を各チャプターに最低2箇所
- ページ端の余白も演出の一部。精神世界ではページ端まで絵が溢れる

## 5. タイポグラフィ

### 日本語版
- **ナレーション**: 明朝体（游明朝 or 筑紫明朝）、縦書き
- **セリフ**: 丸ゴシック系（UD新ゴ丸）、横書き吹き出し
- **精神世界の声**: 手書き風、吹き出しなし、画面に浮遊
- **ゴーストの声**: 細い明朝体、半透明処理

### 英語版
- **Narration**: Serif (Garamond or Baskerville), italic
- **Dialogue**: Sans-serif (Avenir or Proxima Nova), regular
- **Spirit voice**: Handwritten style, no speech bubble
- **Ghost voice**: Light weight serif, opacity 60%

---

## 6. 音の表現

### サウンドリファレンス（読者の脳内BGM）
- **Choro Club** — ARIA のサウンドトラック。日常の温かみと静けさ
- **Freetempo** — 電子音と生楽器の融合。水の都のテクスチャ

### 視覚化ルール
- 効果音は原則として文字にしない
- 音は「線の振動」「水の波紋」「光の粒子」で視覚化
- 爆発音・衝撃音の代わりに、空間の歪みや色の飛散

## 7. キャラクタービジュアル指針

### Tamaki（環樹）
- 佇まいに意志がある。静かだが芯が強い
- 服装: 機能的、水の都に適した素材感（撥水、通気性）
- 精神世界での姿: 通常と同じだが、周囲の空間が彼女に反応する

### Nei-chan
- Tamaki の隣にいることが自然な存在
- 服装: Tamaki より少し柔らかいシルエット
- 猫のモチーフが自然に現れる（影、シルエット、持ち物）

### Elias / Logos
- 二面性。現実世界では物理学者の知性、精神世界ではゴーストの不在
- ゴースト状態: 「線の不在」で表現

### Ren / Akito
- 統合前: 二重露光のような存在。一人の身体に二つの影
- 統合後: 影が一つになり、線がクリアになる

---

## 8. 世界観ビジュアル

### 水の都・東京 2065
- 海面上昇後の東京。水路が道路を置き換えている
- ARIAのネオ・ヴェネツィアに近いが、テクノロジーが有機的に融合
- 情報は空気中に漂う粒子のように可視化される
- 建築は呼吸する。壁面は苔とコードが共生

### 精神世界
- クライアントの内面が空間化する
- 各エピソードで異なる景観（図書館、砂漠、海底、森）
- 感情が天候になる（悲しみ=雨、怒り=雷、安堵=晴れ間）
- ゴーストは景観の一部として溶け込んでいる

## 9. 制作ワークフロー

```
script.md → storyboard.jsonld → ラフ → 線画 → 水彩着色 → タイポグラフィ → 最終
    ↑                ↑
emotion-map.jsonld   ↑
（感情データ）    コマ割り・構図指示
```

### 各チャプターの制作ファイル構成
```
chapterNN/
├── script.md           # セリフ・ナレーション（日本語）
├── script.en.md        # セリフ・ナレーション（英語）
├── storyboard.jsonld   # コマ割り・構図・カメラ指示
├── emotion-map.jsonld  # 感情曲線 → ビジュアル演出対応表
├── roughs/             # ラフスケッチ
├── inks/               # 線画
├── colors/             # 着色済みページ
└── finals/             # 最終納品ページ
```
