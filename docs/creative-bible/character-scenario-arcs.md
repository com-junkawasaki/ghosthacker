# Ghosthacker — 人物別シナリオ成長線

状態: **private canonical scenario direction**

正本: `series-authorial-core.md`

## シナリオ共通構造

各人物の成長は、思想の説明や改宗ではなく、次の四段階を同じ状況の反復で見せる。

1. **呪いの有用性** — 偏りが事件を一度は解決し、本人も読者も正しいと思う。
2. **自分の最善手による失敗** — 外敵ではなく、その人物の「正しさ」が守る対象を傷つける。
3. **異なる伝統との接触** — 教える人物は答えを言わない。本人の命題と両立しない生き方を見せる。
4. **hack／払い** — 同じ型の危機で、以前と違う行動を一つ選ぶ。台詞で成長を要約しない。

診断名や俗称は作者の非公開メモであり、事件、台詞、悪役を自動生成する分類ではない。既存profileの
臨床ラベルと本書の作者ラベルが異なる場合、本書では**観察可能な偏り**だけを正本とする。医学的設定の
変更は別の監修・決定を要する。

## 1. Ren — 正解を見つけても、共に感じられない

**作者軸:** 人の心を推論できるが情動的な共鳴が弱い。既存のADHD設定とは併存しうるが、犯罪性と
結びつけない。

- 種: 最短経路で被害を止める。泣いている被害者を見ず、正しい手だけを選ぶ。
- 失敗: 首魁へ届くため一人の証言者を「許容損失」にし、事件には勝つが関係を失う。
- 接触: 赤羽の祭礼で、個人名を持たない役割も関係の網によって存在することを見る。神道を解説する
  のではなく、誰も所有しない境内を皆が手入れする行動で示す。
- hack: 同じ計算結果を前に、最短経路を捨てて証言者の同意を待つ。rootを取らず、関係に責任を持つ。
- 到達点: 「自分が存在しない」を自己否定ではなく、**関係性こそが自らの存在**だと知る。

**既存アークへの配置:** Arc 16「父を書いた男」で種、Part 2 Overflowで失敗、Part 3で払い。

## 2. Nei — 測れない感情を、無いことにする

**作者軸:** 自他の感情を同定・共有しにくい科学者。強い感情の揺らぎと愛から非分離を学ぶ。

- 種: ログと統計から、誰より早く異常を断定する。
- 失敗: 愛する相手の反応をノイズとして除外し、正確なモデルで本人を誤る。
- 接触: 情報が物理なら、観測するNei自身も系の外にいない。測定のため触れたことで相手と自分の
  状態が変わる場面を、身体反応と沈黙で見せる。
- hack: 分からない感情に仮ラベルを付けず、「分からないまま、ここにいる」を選ぶ。
- 到達点: 非分離を理論として証明せず、解析不能な揺らぎを排除しない「いい感じ」を覚える。

**既存アークへの配置:** Arc 13「ログが、燃えた」で種、Part 2 Memory Leakで失敗、魚拓を開かず
手放す場面で払い。

## 3. Kaname — 愛される価値を、正しさで証明する

**作者軸:** 自分を第一に愛し、完全な自分を維持するため他者を自己像へ従属させやすい。既存profileの
向社会型サイコパシーとは異なるため、シナリオでは**自己愛的防衛**を正本とし、診断変更は行わない。

- 種: 完璧な証拠束と手続きで制度を動かし、皆から必要とされる。
- 失敗: 「自分が正しい限り皆を救える」と信じ、仲間の異議を未熟さとして退ける。印籠が効かない
  国際会議で、誰も彼を特別扱いしない。
- 接触: 仏教の無我を「自分には価値がない」と誤読する。後に、モーセとキリストから連なる愛は
  個人の完成度によらず、関係の中ですでに与えられていると知る。
- hack: 正しさを証明できないまま「手続きは踏んでいません」と告げ、他者に判断を返して動く。
- 到達点: 神の愛を所有せず、大いなる愛の中に自分も他者もいると受け取る。

**既存アークへの配置:** Arc 10／14で種、Part 2「Legacy System」で失敗、Part 3で払い。

## 4. Akaba／Chise Akabane — 感じたものを、全部自分の責任にする

**作者軸:** `Akaba`は現行の赤羽千世に対応する制作名とする。既存ASD設定を消さず、ここでは感覚・
感情を受け取りすぎて境界を引けない困難を扱う。

- 種: 被害者の恐怖を身体で拾い、誰より先に現場へ着く。
- 失敗: 「見捨てない」を「全部引き受ける」に変え、有害な親・友人・依頼人との縁を切れず、共倒れに
  なる。共感が救いではなく侵入路になる。
- 接触: 教会の保護室で「赦すこと」と「同じ場所に居続けること」は別だと、施錠、別室、同行者という
  配置から学ぶ。説教で解決しない。
- hack: 相手の痛みを否定せず、連絡経路を閉じ、第三者へ渡し、自分はその場を離れる。
- 到達点: 良いものを選んで自分の縁とし、悪い縁から逃れる。**共感しない自由**を得る。

**既存アークへの配置:** Arc 2で種、Arc 15で境界の伏線、Part 2で失敗と離脱、Part 3で選んだ縁へ戻る。

## 5. Nue — 自分の感情だけが、閉じた世界のすべてになる

**作者軸:** 他者感情の理解は難しいが、自分の感情を強く感じる。ユダヤ思想とハッカーカルチャーを
入口に、神道からつながりを学ぶ。

現行では`nue`が七尾歩のハンドルとして使われている。一方、作者核ではNueと吃音人物が別枠である。
この衝突が解決するまで、**新しい実名、台詞、episodeを確定しない**。以下は役割の正本だけとする。

- 種: 一人で完結する隔離環境を作り、侵入を完全に防ぐ。
- 失敗: 他者の不可解な反応を攻撃と解釈し、守った系から人を締め出す。
- 接触: 祭りの準備で、自分が読めない感情の代わりに、役割、道具、場所の連鎖が自分を支えていたと
  気づく。
- hack: 心を読めないまま、相手の参加経路だけを開けて待つ。
- 到達点: 孤独な個体ではなく、理解できない他者を含む関係の中に存在すると知る。

## 6. 七尾歩 — 声が詰まる前に、対話を諦める

**作者軸:** 吃音によってコミュニケーションを恐れる人物。現行の七尾歩を正本とする。

- 種: コードとチャットなら誰より速く、対面の言葉を使わず事件を解決する。
- 失敗: 伝わらないと決め、必要な拒否を言わなかったことで、自分のコードが同意として利用される。
- 接触: 相手が言葉を補わず、急かさず、沈黙を会話の時間として待つ。
- hack: 流暢に話すのではなく、音声、文字、合図から自分で経路を選び、「違う」と伝える。
- 到達点: コードで話すことも自分の声であり、待ってくれる関係を選べる。

**既存アークへの配置:** Arc 5で種、Arc 17で最初の払い、Part 2で同意の失敗、Part 3で自分の命令を書く。

## 7. 久我澪 — すべてが最優先になり、権限で順序を固定する

**作者軸:** ADHD特性により優先順位を固定しにくい人物。現行の久我澪を正本とする。

- 種: 即断と多動で、制度が間に合わない危機を救う。
- 失敗: 全件を最優先としてroot権限で同時に動かし、守るべき人の選択権を奪う。
- 接触: 自分より遅い人が、外部化した約束と順番によって毎日続けている姿を見る。
- hack: 優先順位を頭の中で決めず、仲間、期限、sunset条項へ外部化し、自分も拘束される。
- 到達点: 「Rootだから正しい」から「間違えたとき自分を修正できるからRoot」へ進み、自分から降りる。

**既存アークへの配置:** Arc 12で種、Part 2 Root Abuseで失敗、Part 3で権限に期限を付けて払い。

## 各episodeの必須フィールド

新規・改稿episodeは、少なくとも次をstory-outlineに持つ。

既存の一行EDNを大規模整形せずに適用するため、当面の具体値は
`character-scenario-arcs.edn`の`:scenario/episode-overlays`を正本とする。各episodeを実際に改稿する
時点でstory-outlineへ取り込み、overlayを削除する。

- `:gh/authorialQuestion` — この話で作者が描きたいこと。
- `:gh/protectedBeing` — 情報によって守られる人物の有り様・関係・選択。
- `:gh/characterBestMoves` — 各人物の善い最善手と、両立しない一点。
- `:gh/boundaryOrConnection` — 今回は境界を引くのか、つながり直すのか。
- `:gh/growthBeat` — 説明ではなく、前と違う行動。
- `:gh/structuralCause` — 犯人の上で歪みを再生産する制度・欲望・首魁。
